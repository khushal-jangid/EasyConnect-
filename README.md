> **EasyConnect** is an ultra-fast, local Wi-Fi PC remote control hub. Control your Windows PC mouse, keyboard, live screen, taskbar apps, webcam, clipboard, and system settings directly from your smartphone browser with **zero cloud dependencies** and **zero lag**.

---

## 🚀 Key Features

- 📱 **Zero Install on Phone:** Simply scan the QR code with your smartphone camera. Runs directly in any modern browser.
- 🖱️ **Precision Trackpad:** Native multi-touch gestures (2-finger scroll, pinch zoom, 3-finger app switcher).
- 📺 **60 FPS Live Screen Streaming:** WebRTC and ultra-fast JPEG fallback with adaptive quality.
- ⌨️ **Comprehensive Controls:** Virtual keyboard with 37+ Windows shortcuts (Alt+Tab, Win+D, Task Manager).
- 🚨 **Intruder Webcam Sentry:** Disguised black screen alert and intruder snapshot capture.
- 🔄 **1-Click Auto-Updater:** Seamless in-app version checks and silent background updates.
- 📦 **Standalone Windows Executable:** No Python or dependencies required for end users.

---

## ⚡ Quick Start (Standalone Executable)

1. Download **`EasyConnect.exe`** from [Releases](https://github.com/khushal-jangid/pulse-remote-pc/releases).
2. Double-click **`EasyConnect.exe`** to start the local Wi-Fi agent.
3. Scan the terminal or window QR code with your smartphone camera to connect instantly!

---

## 🛠️ Running from Source

```bash
# Clone the repository
git clone https://github.com/khushal-jangid/pulse-remote-pc.git
cd pulse-remote-pc

# Install dependencies
pip install -r requirements.txt

# Run Agent
python agent.py
```
